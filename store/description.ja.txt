範囲を選んで、隠して、囲って、指して、そのままクリップボードへ。画像はマシンの外に出ません。

Snap Redact は、ページの一部を Slack やバグ報告やドキュメントに貼りたいとき、見せたくない所を黒く塗り、見てほしい所に矢印を付けて、そのままコピーするための拡張です。一往復で終わります。エディタのタブも、アカウントも、アップロードもありません。

使い方
1. ツールバーのアイコンをクリック、右クリックメニュー、または Cmd+Shift+E（Windows / Linux は Ctrl+Shift+E）
2. ドラッグで範囲を選ぶか、要素をクリックしてその要素をぴったり選ぶ。Cmd+A / Ctrl+A で表示領域の全体
3. 隠す（1）、囲う（2）、矢印（3）。選択範囲の中でドラッグして描くか、要素をクリックしてその要素をぴったり隠す / 囲う
4. コピー（Cmd+C か Enter）または PNG で保存（Cmd+S）。以上

復元できない隠し方
「隠す」は不透明な単色で塗りつぶします。ぼかしとモザイクはあえて用意していません。どちらも元に戻せることがあり、一度共有したスクリーンショットは取り消せないからです。隠した所は画像から消えています。

マシンの外に出ない
- サーバーも、クラウドも、解析も、クラッシュ報告も、外部フォントもありません
- storage 権限を取っていないので、設定すら保存しません
- 撮った画像はページの中で処理して、クリップボードかダウンロードに渡すだけです

インストール時の警告なし
権限は activeTab、scripting、contextMenus の 3 つだけ。どれも警告が出ません。clipboardWrite と downloads はあえて取っていません。

こんな人に
- バグ報告を書く開発者と QA
- お客様の画面をアカウント情報を隠して共有するサポート担当
- チャットやドキュメントにスクリーンショットを貼るすべての人

細かいこと
- 要素の選択: ポインタの下の要素を点線で示し、クリックでその矩形を取ります。ページ自体は書き換えません
- 選択範囲は矢印キーで動かせます（Shift で 10px）。縁の 8 つのハンドルで伸縮できます
- Retina 品質: 画像はデバイスのピクセル数で書き出します
- ホバー中にだけ出るメニューやツールチップは、ショートカットで起動するとポインタを動かさずに撮れます
- 日本語と英語。表示はブラウザの言語に従います
- 範囲の選択だけ。ページ全体のキャプチャはあえて含めていません
