# Snap Redact

[English](README.md)

範囲を選んで、隠して、囲って、指して、そのままクリップボードへ（Chrome 拡張）。

## 思想

- **インストール警告ゼロ**: `permissions` は `activeTab` / `scripting` / `contextMenus` のみ。どれも警告が出ない
- **外部通信ゼロ**: 解析・クラウド送信・外部フォント一切なし。スクリーンショットはマシンから出ない
- **一往復で終わる**: モード選択もエディタタブもなし。選んで、印を付けて、コピー
- **必要最小限の機能**: 範囲選択のみ。ページ全体のキャプチャは他がすでに十分やっている
- **日本語と英語**: 表示はブラウザの言語に従う。選ばせる設定も、覚えておく保存先も持たない

## プライバシー

収集も送信もしない。撮った画像はページ内で処理して、クリップボードかダウンロードに渡すだけ。
`storage` 権限を取っていないので、拡張側に何も保存されない。
詳細は [プライバシーポリシー](PRIVACY.md)（英語）を参照。

## 開発

```bash
npm install
npm run build   # dist/ に出力
```

ビルドしたものを手元の Chrome で動かす場合:

1. `chrome://extensions` を開く
2. 右上「デベロッパーモード」を ON
3. 「パッケージ化されていない拡張機能を読み込む」→ `dist/` フォルダを選択

## 使い方

ツールバーのアイコンをクリックするか、ページを右クリックしてメニューを選ぶ。
キーボードショートカットは既定で割り当てていない。押しやすい組み合わせは他のアプリと衝突するため。
必要なら `chrome://extensions/shortcuts` で好きなキーを割り当てられる。

| 操作 | キー |
|---|---|
| 範囲を選ぶ | ドラッグ |
| 選択範囲を調整する | 縁のハンドルをドラッグ |
| 図形を描く | 選択範囲の中でドラッグ |
| 隠す / 囲う / 矢印 | `1` / `2` / `3` |
| 取り消す | `Cmd+Z` |
| コピー | `Cmd+C` または `Enter` |
| PNG で保存 | `Cmd+S` |
| ヘルプ | `?` |
| 中止 | `Esc` |

## 構成

```
src/
  domain/        純粋なルール。DOM も chrome.* も触らない。ユニットテスト済み
  application/   ブラウザ API 越しの副作用（キャプチャ・クリップボード・保存・通知）
  presentation/  オーバーレイ。Shadow DOM、canvas、イベント
  background.ts  Service Worker。入口が 2 つあるだけ
  content.ts     注入されるスクリプト。二重注入を防ぐ
```

`domain` は上の層を import しない。
壊れやすいところ（キー解釈、矢印の幾何、どのページで使えるか）を素の Node でテストできるのは、この向きを守っているから。

## Notes

- **隠すのは常に不透明な単色**。モザイクとぼかしは復元されうるので用意していない
- **選択範囲は拡大縮小できるが、移動はできない**。縁の 8 つのハンドルで調整する。
  そのまま平行移動する操作は用意していない。対辺を 2 回引くか、引き直す
- **描いた図形は移動もリサイズもできない**。取り消してから引き直す
- **テキスト注釈はない**。「矢印のところ」と画像の横に書けば足りる
- **使えないページがある**。ウェブストア、`chrome://`、および「ファイルの URL へのアクセスを許可」が OFF のときの `file://`。
  エラーを出すポップアップを持たないので、ツールバーアイコンに赤い `!` と理由の tooltip を出す
- **`clipboardWrite` はあえて取っていない**。付けると「コピー＆ペーストするデータの変更」という警告が出るため。
  代わりにキー操作を起点に呼んで権限なしで通している。`http:` のページではブラウザ側がコピーを拒否するので、
  オーバーレイが保存に誘導する
