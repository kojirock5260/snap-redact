Snap Redact

Select an area, hide it, box it, point at it, then straight to the clipboard.

A Chrome extension. No install warnings, and nothing leaves your machine.

Install from the Chrome Web Store GitHub

Principles

No install warnings

Only activeTab, scripting and contextMenus. None of them shows a warning.

Nothing leaves your machine

No server, no analytics, no cloud, no external fonts. The capture is processed inside the page.

One trip

No mode picker, no editor tab. Select, mark, copy.

Redaction that cannot be reversed

Hide paints a solid, opaque block. No blur, no mosaic.

How it works

  1. Click the toolbar icon, use the right-click menu, or press Ctrl+Shift+E (Cmd+Shift+E on Mac).
  2. Drag an area, or click an element to select exactly it.
  3. Hide (1), Box (2) or Arrow (3). Drag to draw, or click an element to hide or box it precisely.
  4. Copy (Cmd+C or Enter), or save as PNG (Cmd+S).

Not included

  • Full-page capture. Other extensions do that well.
  • Text annotation. Writing "see the arrow" next to the image is enough.
  • What the browser draws itself (native context menus, select dropdowns, tooltips) is outside the page and is not captured.
